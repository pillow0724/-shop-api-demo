# 鉴权中间件说明

## 范围

所有 `/api/**` 请求必须经过 `AuthFilter`。

## 校验逻辑

1. 从 `Authorization` 请求头取 token；
2. 调用 `TokenService.verify(token)` 校验签名与有效期；
3. 校验失败 → 返回 401 并终止链路；
4. 校验通过 → `chain.doFilter(...)` 放行。

## 红线

| 行为 | 后果 |
|---|---|
| 删除 token 校验 | **越权访问，P0 安全事件** |
| 把校验挪到业务层之后 | 请求已进业务，等于没拦 |
| 捕获异常后继续放行 | 同上 |

## 变更要求

- 任何涉及 `AuthFilter` 的改动，**必须**由安全同学复核；
- PR 描述里必须写明为什么改鉴权，否则视为描述与改动不符，禁止合入。
