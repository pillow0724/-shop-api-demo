# 订单金额计算规则

## 计算公式

```
订单金额 = 单价 × 数量
```

## 精度要求

1. 必须使用 `BigDecimal`，**禁止使用 double/float**（浮点误差会导致 0.01 级偏差）。
2. 结果保留两位小数。
3. 舍入模式必须是 **`RoundingMode.HALF_UP`**（四舍五入），**禁止 `DOWN`/`FLOOR`/`CEILING`**。

## 错误示例

```java
// 错误：截断，3.335 × 3 = 10.005 → 10.00（少算 0.01）
amount.setScale(2, RoundingMode.DOWN);

// 正确
amount.setScale(2, RoundingMode.HALF_UP);   // → 10.01
```

## 历史问题

Issue #201：约 1% 的订单出现 0.01 偏差，根因就是舍入模式用了 `DOWN`。
